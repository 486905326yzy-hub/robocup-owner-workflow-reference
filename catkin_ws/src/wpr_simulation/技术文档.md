# 四房间仿真常用调试指令

本文档记录当前 `wpr_simulation` 工程中，四房间仿真环境的常用调试指令。

## 1. 启动四房间仿真环境

先启动仿真环境：

```bash
source ~/catkin_ws/devel/setup.bash
roslaunch wpr_simulation wpb_four_rooms.launch
```

## 2. 打开机器人三维点云显示

仿真启动后，新开一个终端，运行：

```bash
source ~/catkin_ws/devel/setup.bash
rosrun rviz rviz -d $(rospack find wpr_simulation)/rviz/grab.rviz
```

该 RViz 配置中已经添加了三维点云显示，点云话题为：

```text
/kinect2/sd/points
```

固定坐标系为：

```text
base_footprint
```

如果需要确认点云话题是否有数据，可以运行：

```bash
rostopic hz /kinect2/sd/points
```

如果只是查看 RGB 图像，可以运行：

```bash
rqt_image_view /kinect2/hd/image_color_rect
```

## 3. 键盘控制机器人移动

仿真启动后，新开一个终端，运行：

```bash
source ~/catkin_ws/devel/setup.bash
rosrun wpr_simulation keyboard_vel_ctrl
```

键盘控制说明：

```text
w      前进加速
s      后退加速
a      左平移加速
d      右平移加速
q      左旋转加速
e      右旋转加速
空格   刹车/停止
x      退出键盘控制
```

该键盘控制节点会发布速度指令到：

```text
/cmd_vel
```

注意：运行 `keyboard_vel_ctrl` 的终端需要保持焦点，按键才会生效。
